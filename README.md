# Facility Work Order Management System

A full-stack web application for managing facility maintenance work orders.

## Demo Video


## Tech Stack
- **Frontend:** Angular 21, Angular Material UI, TypeScript
- **Backend:** ASP.NET Core Web API, C#, Entity Framework Core
- **Database:** SQLite (dev) / SQL Server (production-ready)

##Features
- Dashboard with real-time stats (total, new, in-progress, completed, high priority)
- Full CRUD work order management
- Color-coded priority and status indicators
- RESTful API with GET, POST, PUT, DELETE endpoints
- Reactive forms with validation
- Material UI responsive design

## Getting Started

### Backend
cd backend
dotnet run
### Frontend
cd frontend
npm install
ng serve
Visit http://localhost:4200
