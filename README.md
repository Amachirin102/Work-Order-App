# Facility Work Order Management System

A full-stack web application for managing facility maintenance work orders.

## Demo Video

https://www.loom.com/share/ecd5bee6e4f54d9dab3e00916a725fb3

## Tech Stack
- **Frontend:** Angular 21, Angular Material UI, TypeScript
- **Backend:** ASP.NET Core Web API, C#, Entity Framework Core
- **Database:** SQLite (dev) / SQL Server (production-ready)

## Features
- Dashboard with real-time stats (total, new, in-progress, completed, high priority)
- Full CRUD work order management
- Color-coded priority and status indicators
- RESTful API with GET, POST, PUT, DELETE endpoints
- Reactive forms with validation
- Material UI responsive design

## Getting Started

### Backend
```
cd backend
dotnet run
```

### Frontend
```
cd frontend
npm install
ng serve
```
Visit http://localhost:4200

## Database
- SQLite database (`workorders.db`), created automatically when the backend first runs
- Schema generated by Entity Framework Core from the `WorkOrder` model
- Single `WorkOrders` table with fields for title, description, priority, status, customer, technician, estimated cost, and timestamps
- Auto-generated work order numbers in the format `WO-yyyyMMdd-XXXX`
- SQL schema and a sample data dump are in the `database/` folder for inspection or local seeding
